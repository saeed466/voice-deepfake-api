# Voice Deepfake Detector — API

كاشف التزييف الصوتي بثلاث درجات ثقة.

## التشغيل

pip install -r requirements.txt
uvicorn api.main:app --reload --port 8000

## الروابط

- Swagger: http://localhost:8000/docs
- Health: http://localhost:8000/health

- #1: معالجة صوتية
- #2: تجربة مستخدم
- #3: تطوير وتكامل
- #4: تحقق الهوية
- #5: كشف التزييف
